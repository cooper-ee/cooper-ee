## 🚀 开源项目 | Featured Projects

### 🤖 [vehicular-agent-infra](https://github.com/cooper-ee/vehicular-agent-infra)

[![Repo](https://img.shields.io/badge/GitHub-vehicular--agent--infra-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/cooper-ee/vehicular-agent-infra)

**面向车路协同计算的 LangGraph Agent 系统**，集成知识检索、卸载时延估算、工具调用与 vLLM 推理服务接入。

* 🔄 **Agent 工作流：** 基于 LangGraph 实现任务状态、条件路由与有界工具循环，衔接模型决策、工具执行和结果反馈。
* 📚 **检索与工具：** 提供车载边缘计算知识检索、来源引用与卸载时延估算工具。
* ⚙️ **服务与可靠性：** 使用 FastAPI 提供接口，支持异步并发控制、超时重试、SQLite 会话持久化、请求去重与缓存。
* 📊 **推理服务与观测：** 提供 vLLM 等 OpenAI 兼容后端接入，配套调用链记录与性能测量入口。

**Tech Stack:** `Python` · `LangGraph` · `FastAPI` · `HTTPX` · `SQLite` · `vLLM API` · `Docker`

### 👁️ [roadside-multimodal-agent](https://github.com/cooper-ee/roadside-multimodal-agent)

[![Repo](https://img.shields.io/badge/GitHub-roadside--multimodal--agent-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/cooper-ee/roadside-multimodal-agent)

**面向路侧视觉场景的端云协同多模态 Agent 原型**，提供 Jetson 视觉采集与检测接入、事件筛选、断网重传、主机 VLM 问答及图像压缩与时延评估。

* 📷 **端侧视觉接入：** 提供 Jetson 摄像头采集与轻量检测接入，通过事件变化、冷却窗口与心跳机制筛选上传内容。
* 📡 **可靠数据传输：** 使用 SQLite 待发队列实现事件持久化、后台上传、指数退避与断网重传。
* 💬 **多模态交互：** 对接主机 VLM 图文接口，关联图像、检测元数据与后续追问。
* 📊 **压缩与时延评估：** 对比图像分辨率与 JPEG 质量，分别记录客户端往返和主机处理耗时。

**Tech Stack:** `Python` · `jetson-inference` · `VLM API` · `Pillow` · `FastAPI` · `SQLite` · `Docker`
